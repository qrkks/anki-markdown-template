# Anki Markdown Template v0.4.0

## English

### What's new

- **SVG diagrams:** `svg` fenced blocks now display responsive SVG images, including embedded styles, gradients, and text. Malformed SVG falls back to a copyable code block. Use `xml` or `html` fences to display source code. SVG image mode does not execute scripts or load external resources.
- **Better outlines:** vocabulary card backs show a floating outline when they contain at least three headings. Outline labels display KaTeX formulas, and controls follow the system language. Markdown Basic outline text is larger, mobile controls are more stable, and formula labels no longer repeat their text.
- **More reliable Markdown:** bold and italic text next to Chinese punctuation and CJK characters renders correctly. Headings containing Anki non-breaking spaces and fenced code saved with HTML line breaks are restored correctly.
- **Smoother card review:** Mermaid loads only for cards that need it; vocabulary content uses a narrower reading width. Moving from a vocabulary answer to the next question clears the previous outline in a reused WebView.

### Downloads and updating

- **`anki-markdown-basic.apkg`** — the general-purpose `Markdown Basic / Basic` template.
- **`anki-english-vocabulary.apkg`** — the `单词` note type with `RECITE`, `SPELLING`, and `DICTATION` templates.
- **`SHA256SUMS.txt`** — checksums for both APKG files.

First-time users can import either or both APKG files through **File → Import** in Anki. Existing managed note types can use the audited AnkiConnect update workflow described in the [README](https://github.com/qrkks/anki-markdown-template/blob/v0.4.0/README.md).

See the [English changelog](https://github.com/qrkks/anki-markdown-template/blob/v0.4.0/CHANGELOG.md) and [changes since v0.3.0](https://github.com/qrkks/anki-markdown-template/compare/v0.3.0...v0.4.0).

## 简体中文

### 新增与改进

- **SVG 图形：** `svg` 围栏代码块现在直接显示响应式 SVG 图片，支持内嵌样式、渐变和文字。格式错误时回退为可复制的代码框；使用 `xml` 或 `html` 围栏可以展示源码。SVG 图片模式不会执行脚本或加载外部资源。
- **更好用的大纲：** 词汇卡背面包含至少三个标题时显示浮动大纲。大纲标题直接显示 KaTeX 公式，控件跟随系统语言；Markdown Basic 大纲字号更大，移动端控件更稳定，公式文字不再重复。
- **更可靠的 Markdown：** 正确渲染紧邻中文标点和中日韩字符的加粗、斜体文本，恢复含 Anki 不换行空格的标题，以及以 HTML 换行保存的围栏代码。
- **更顺畅的复习：** 仅在需要时加载 Mermaid；词汇卡正文使用更适合阅读的窄版宽度。在复用的 WebView 中从词汇卡背面进入下一张正面时，清理上一张的大纲。

### 下载与更新

- **`anki-markdown-basic.apkg`** — 通用的 `Markdown Basic / Basic` 模板。
- **`anki-english-vocabulary.apkg`** — `单词` 笔记类型及 `RECITE`、`SPELLING`、`DICTATION` 三套模板。
- **`SHA256SUMS.txt`** — 两个 APKG 文件的校验和。

首次使用可在 Anki 中通过 **文件 → 导入** 安装其中一个或两个 APKG。已有受管笔记类型可使用 [README 中的审计与更新流程](https://github.com/qrkks/anki-markdown-template/blob/v0.4.0/README.zh-CN.md)，通过 AnkiConnect 更新模板。

参见[中文更新日志](https://github.com/qrkks/anki-markdown-template/blob/v0.4.0/CHANGELOG.zh-CN.md)和[相对 v0.3.0 的完整改动](https://github.com/qrkks/anki-markdown-template/compare/v0.3.0...v0.4.0)。
