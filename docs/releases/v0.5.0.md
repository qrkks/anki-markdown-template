# Anki Markdown Template v0.5.0

## English

- **Linked images:** Markdown links to recognized image URLs now display clickable, responsive images, including extensionless links from `images.openai.com`.
- **SVG without a language label:** an unlabeled fenced block containing a complete, valid SVG document now displays as an image. Ordinary code, malformed SVG, and explicit `xml` / `html` fences remain copyable code.
- **Source icons:** Google S2 favicon links show compact 16px site icons. A standalone favicon link followed by a short source name becomes one clickable source label.
- **Markdown security update:** the bundled parser and pinned CDN fallback now use markdown-it 14.3.3, addressing known parsing performance vulnerabilities.

Both `anki-markdown-basic.apkg` and `anki-english-vocabulary.apkg` include the updated renderer. `SHA256SUMS.txt` contains their checksums. Remote images and site icons require a network connection or an existing WebView cache; they are not bundled into the APKG.

See the [update instructions](https://github.com/qrkks/anki-markdown-template/blob/v0.5.0/README.md), [English changelog](https://github.com/qrkks/anki-markdown-template/blob/v0.5.0/CHANGELOG.md), and [changes since v0.4.0](https://github.com/qrkks/anki-markdown-template/compare/v0.4.0...v0.5.0).

## 简体中文

- **链接图片：** 指向可识别图片地址的 Markdown 链接直接显示为可点击的响应式图片，支持 `images.openai.com` 提供的无文件扩展名链接。
- **无语言标签的 SVG：** 未标注语言的围栏代码块包含完整、有效的 SVG 文档时，自动显示为图片。普通代码、格式错误的 SVG，以及明确使用 `xml` / `html` 的围栏仍显示为可复制的代码。
- **来源图标：** Google S2 favicon 链接显示紧凑的 16px 网站图标；独立图标链接后紧跟简短来源名时，合并为一个可点击的来源标签。
- **Markdown 安全更新：** 打包的解析器及固定版本 CDN 回退资源更新至 markdown-it 14.3.3，修复已知的解析性能漏洞。

`anki-markdown-basic.apkg` 和 `anki-english-vocabulary.apkg` 均包含新版渲染器，`SHA256SUMS.txt` 提供两个安装包的校验和。远程图片和网站图标需要网络连接或已有的 WebView 缓存，不会打包进 APKG。

参见[更新方法](https://github.com/qrkks/anki-markdown-template/blob/v0.5.0/README.zh-CN.md)、[中文更新日志](https://github.com/qrkks/anki-markdown-template/blob/v0.5.0/CHANGELOG.zh-CN.md)和[相对 v0.4.0 的完整改动](https://github.com/qrkks/anki-markdown-template/compare/v0.4.0...v0.5.0)。
